## 2. variants.json

- 来源：手工整理，对照《简化字总表》与《第一批异体字整理表》的**字符级**映射。
- 方向：只收 **繁→简** 与异体归一；**不收简→繁**。
- 粒度：单字符，不做词组转换（避免「头发/頭髮」这类词级歧义）。
- 刻意不收的歧义字：`乾`（干/乾 Qian 分属不同词义）、`著`（著/着）、`藉`（藉/借）。
- 数据格式：`{"version":1,"pairs":[["繁","简"], ...]}`，无浮点。

## 3. kinship.json / kinship_labels.json

### 3.1 来源与规模

- 参考《现代汉语词典》亲属称谓条目与日常称谓习惯整理。
- 方言变体：粤语「阿妈 / 阿嬷 / 阿公」，川渝「老汉儿」。
- 共 126 条：`kin` 116 条、`fictive` 6 条、`social` 4 条（满足 ≥120 条标注）。

### 3.2 判据

- 边序列语法见规格 §3.1：`F/M/H/W/OB/YB/OS/YS/s/d`，如 `F.OB.s`。
- `candidates` 按常见度排序；`ambiguous = len(candidates) > 1`。
- 堂 / 表：父系兄弟之子为「堂」，其余（姑、姨、舅之后）为「表」。
- 长幼：`age` 只取 `older` / `younger` / `null`；词面无法判断时为 `null`。
- **拟制与社会称谓硬规则**：`kind != kin` 时 `candidates` 必须为 `[]`。
  - `fictive`：干爹/干爸/干妈/干娘/干哥/干姐，给 `role`，**绝不借血缘边**。
  - `social`：师傅/师父/老师/老板，`candidates=[]`，给 `role`。
  - `阿姨`：`kind=kin`、`candidates=["M.S"]`，并标 `may_be_social=true`。
- 多义词保留并列候选并标 `ambiguous=true`：先生、爱人、媳妇、弟妹。
- 继承/收养/结义（继父母、养父母、义父母）按 `kin` 处理，边映射到 `F` / `M`，note 注明关系性质。
- 未收录词一律抛 `E_CN_UNKNOWN_TERM`，不猜。

## 4. timex_labels.json

### 4.1 分类

- **A 类 120 条**：可精确判定，给 `start`/`end`。
- **B 类 40 条**：模糊/事件锚定，`start`/`end` 一律 `null`，只标 `certainty` 与 `granularity`。
- **C 类 20 条**：农历与节气，M2 不支持，必须抛 `E_CN_PARSE` 且信息含「农历」。
- **畸形输入 50 条**：40 条解析失败（`E_CN_PARSE`）+ 10 条锚点缺失/无时区（`E_CN_BAD_ANCHOR`）。

### 4.2 锚点与窗口口径

- 所有锚点带时区，先换算到 `UTC+08:00` 再计算；锚点覆盖月末、年首、跨年周等边界。
- 日历窗口一律**三分法**，不写死天数：
  - 月：`k = 当月天数 // 3`；月初 1..k，月中 k+1..2k，月底 2k+1..月末。
  - 季：季初/季中/季末 = 该季第 1/2/3 个月整月。
  - 年：年初 1–4 月，年末 9–12 月。
- 周：周一至周日。
- 点时间：`三天前` = 减 3 天；`半个月前` = 减 15 天；`半年前` = 减 6 个日历月；
  `三年前` / `十年前` / `去年这时候` = 同月同日按年平移（2 月 29 日落到 2 月 28 日）。
- `月初一` 按「当月 1 日」标注（day/exact）。
- B 类不给区间：`春节前/春节后/秋收后/入冬前` = season/vague；`过了年/年底前` = year/vague；
  `最近/那阵子/前几天/过几天` = day/vague；`等孩子高考完/等我出院/等我退伍` = event/unknown。
- C 类农历节日明确不支持，留 M2.1；公历节日（元旦/劳动节/国庆/儿童节）标当天。

## 5. slang.json / slang_holdout.json

### 5.1 来源

- 年份依据：百度指数峰值年、抖音播放量峰值、微博话题量、小红书笔记量的公开峰值年份；
  逐条写入 `source`，便于审计。
- `confidence` 为证据强度 0–100；**`confidence < 60` 只用于展示，不参与 usable 判定**
  （本数据中：老登 55、听君一席话 58）。
- 曲线与 looked-up 判定以规格 §5.1 为准；`born <= peak <= cringe` 已逐条断言。

### 5.2 留出集

- `slang_holdout.json` 的 24 条**逐字来自规格附录 A**，未做任何修订。
- 实现代码禁止读取该文件；只有 `tests/test_cn_slang.py` 可以读。
- 若将来修订，必须在本文保留原值并注明日期；当前 v0.1 无修订。

## 6. 数据纪律

- 所有 JSON 均为 UTF-8、LF 换行、**不含任何浮点数**（年份 int、分数 int、置信度 int）。
- 本目录不依赖任何第三方库生成；生成脚本未入库。
- 提交顺序：commit A（本目录 + 本文件）→ commit B（`jian_cn/` 实现与测试）。
