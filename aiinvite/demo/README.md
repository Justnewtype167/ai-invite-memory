# 最小可信演示（B）

> 目的：让任何人在 60 秒内看懂「换模型不掉人格」是什么意思。
> **不是产品**，是地基的说明书。零第三方依赖（tkinter + urllib）。

---

## 跑起来

```bash
pip install -e .            # 或 pip install ai-invite-memory
python -m demo.app          # 打开窗口
```

没装 Ollama 也能开窗口，只是发消息会提示连不上。

---

## 界面（四块）

```
┌────────────────────────────────────────┬──────────────────┐

├────────────────────────────────────────┤                  │

```

右侧三个按钮：**导出人格 / 导入人格 / 校验证据链**。

---

## 这个窗口要证明的四件事

| # | 操作 | 你会看到 |
|---|---|---|
| D1 | 说一句话 | 用户轮与它的话都进证据链；被闸门拒绝时标【闸门拒绝】 |
| D2 | **按「换模型」** | 换模型这个动作**不改 kid**（窗口会打印 unchanged）；再问一次时回答换了模型的声音，但卡还是那张 |
| D3 | 看保险箱 | 名字/忌讳被机械抽成一张 ≤400 字的卡 |
| D4 | 导出 → 换台机器导入 | kid 与卡一致，它仍然认得你 |

**D2 是核心**：它把「人格不活在权重里」从一句话变成一个可看见的事实。

---

## 它不证明什么

```
× 「像他」—— 这一层没有指标（见 docs/RESULTS-style-sweep.md）
× 长期关系 —— 需要真实用户数周使用
× 「导入任何平台」—— 只有实现同一协议的载体才收得住
```

## 结构

```
demo/
  engine.py   纯逻辑：会话封装、状态快照、导出导入（可测，无 UI）
  app.py      tkinter 窗口（只做展示与按钮）
tests/test_demo_engine.py   D1–D5，用假模型调用，不碰网络
```

**逻辑与窗口分开**，所以 CI 里不需要图形环境。
