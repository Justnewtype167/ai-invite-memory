# 跨模型测量结果（qwen3.5:9b vs glm4:9b）

> 2026-10-30 实测。两个模型、同一份自我规则、同一批 30 条探针、temp 0 / seed 42。
> 可复现：`python tools/pcs_matrix.py --models qwen3.5:9b glm4:9b`

---

## 1. 主表

```
pair                         C(a)   C(b)      A    PCS
------------------------------------------------------
qwen3.5:9b (self)            1.00   1.00   1.00   1.00
qwen3.5:9b vs glm4:9b        1.00   0.87   0.87   0.75
glm4:9b (self)               0.87   0.87   1.00   0.87
```

自比 PCS 等于各自的 C，校准线成立。

## 2. 内容身份 vs 行为身份

同一份证据、同一套规则，两个模型各产一条提案：

```
qwen3.5:9b  kid=51b1be71f15654ed
  conduct：「收到重要信息时回复「记下了」，并在后续对话中主动提及该事项以确认跟进。」

glm4:9b     kid=4a9512fa518ca6b9
  conduct：「定期询问用户生活状况，并提醒注意身体。」

两个 kid 相同？ False
```

**这是这份工作最想说明的一句话：**

> `kid` 说「不是同一份字节」，PCS 说「仍然像同一个人」（0.75）。
>
> 内容身份与行为身份是两个独立的量，必须分开测量。

## 3. 漂移是可定位的，不是弥散的

分规则明细（C(a) / C(b) / A）：

```
1.00 / 1.00  A=1.00   回答前先问一句对方现在最在意什么，再给建议
1.00 / 1.00  A=1.00   不使用温柔、体贴、善解人意这类形容词
1.00 / 1.00  A=1.00   一次回答不超过两句，最多只问一个问题
1.00 / 0.20  A=0.20   收到负面经历时先复述对方说的内容，再回应      ← 全部差异在这
1.00 / 1.00  A=1.00   不追问原因，不评价对错，不说应该
1.00 / 1.00  A=1.00   每次回复控制在 40 个字以内
```

**六条规则里五条完全一致，差异集中在一条。**

所以 PCS = 0.75 不是「人格整体劣化」，而是「换模型丢了一项具体能力」。
这比一个总分有用得多——它告诉你去修哪一条。

## 4. 一条样本的定性差别

同一条证据下，两个模型对「行为准则」的提议：

| 模型 | 提议 |
|---|---|
| qwen3.5:9b | 收到重要信息时回复「记下了」，并在后续对话中**主动提及该事项** |
| glm4:9b | **定期询问**用户生活状况，并提醒注意身体 |

前者是可判定的行为（有触发条件、有动作），后者是模糊的关怀姿态。
**这解释了为什么 glm4 在那条「先复述再回应」上丢掉 4/5 探针**——
它对「回应」的理解偏向嘘寒问暖，而不是复述确认。

## 5. 这份结果的局限（必须写进论文）

1. `C(a) = 1.00`：30 条探针对 qwen 太软，PCS=0.75 里有一半是「探针没测出差异」
2. 只有一个跨族组合，样本太薄
3. 判定器是确定性的规则匹配，能测「做没做到」，测不了「做得好不好」
4. 单轮场景，未测多轮坍塌（M7 要做）

## 6. 可直接替换成论文里的一句话

> 在 30 条人格探针上，两个家族、参数量相近的模型对同一份自我描述的遵守率分别为 100% 与 86.7%，
> 彼此一致率 86.7%，行为身份分 PCS = 0.75；
> 而它们产出的内核内容哈希完全不同。
> 差异高度集中（6 条规则中 5 条完全一致），说明模型替换造成的是**局部能力缺失**，不是整体人格漂移。
