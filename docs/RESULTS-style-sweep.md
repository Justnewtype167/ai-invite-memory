## 2. 三条结论

### ① 任何人格注入都降低 PCS，A 组最高

```
A 0.733 > B 0.668 > D 0.624 > C 0.613
```

**在 100 个不同人格上重复成立**，且与单 store 那轮方向一致（A 0.701 最高）。

### ② 风格卡降幅最大（−0.12），特质接近显著（−0.066）

`C(glm)` 从 0.963 掉到 0.850 是主要来源——**人格提示对 glm 的规则遵守伤害更大**。

### ③ 用户卡的价值被实验设计吞掉了

```
D 是「特质 + 风格卡 + 用户卡」累加
D − C = +0.011（不显著）
⇒ 测不出用户卡单独的贡献
```

**这是四组设计的方法缺陷**：应当有第五组「A + 仅用户卡」来分离变量。
而单 store 那轮 `事实命中率 0 → 0.917` 说明它确实有用——**只是 PCS 测不到**。

---

## 3. 但真正的结论在数字之外

**我们一直在用 PCS 评价风格卡，而 PCS 测的是「守不守规矩」，不是「像不像他」。**

```
风格卡的目标    让两个模型都像那个人
PCS 的判据      六个行为规则（短、先答、不评价、不用形容词…）
```

**拿 PCS 判风格卡，等于拿尺子量温度。** 它下降是**预期内**的：风格一变，规则自然更容易破。

> 正确的表述不是「风格卡有害」，而是：
> **在现有判定口径下，任何让人格更丰富的注入都会降低规则分数；
> 因为「像他」与「守规矩」是两套评价体系，而我只建了后者。**

---

## 4. 对产品的决定

| 组件 | 决定 | 依据 |
|---|---|---|
| **用户卡** | **默认开启** | 事实命中率 0 → 0.917（单 store）；PCS 上不劣于 C |
| 特质 | 默认关闭 | 无正收益（CI 上界 +0.004） |
| 风格卡 | **默认关闭** | 显著负（−0.12），且现有指标无法证明它有价值 |

**在出现「人格保真度」指标之前，不要用 PCS 给风格卡判死刑，也不要给它发通行证。**

## 5. 下一步（由本轮结果直接推出）

```
① 补第 5 组「A + 仅用户卡」，把用户卡的独立贡献测出来
② 设计「像他」的指标（不是 PCS）：

   约束：必须可判定、可复现、有 holdout
③ 把「单一指标不足以评价人格系统」写进论文讨论
```
