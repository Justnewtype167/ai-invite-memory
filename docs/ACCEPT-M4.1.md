## 4. 这一轮的方法学收获

我自己犯了一个错并当场上报：**用 `v0.3-m3` 作基线去检查 `jian_kernel/`**，
而那个包在 v0.3-m3 时还不存在，于是整包被显示为「新增」——看起来像违规。

换成正确基线后零 diff。

**教训**：核对冻结范围时，基线必须选在「该包已存在」的那一版之后。
否则你会把「创建」误判成「修改」。这条已记入 `docs/SPEC-CHECKLIST.md` 的元规则。
