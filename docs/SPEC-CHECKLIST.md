# 规格自检清单（每次写规格前跑一遍）

> 这份清单来自 M1–M3 的 **11 处规格缺陷**，全部由实现方提问暴露，全部由规格方造成。
> 用法：写完任何一节规格，逐条问一遍。**十问里能挡住八处。**

---

## 一、十一处缺陷的归类

| 类 | 缺陷 | 代价 |
|---|---|---|
| **语义未定义** | `created` 取内容时间还是容器时间 | 实现方只能猜，猜错就要返工 |
| | seal 之后还能不能 append | 冻结 vs 快照，两种产品形态 |
| | 未 seal 的目录能不能 verify | 决定「只留证据能复活」是否成立 |
| | 质量测试里 N 与基线的关系 | 基线 < 1 时比值失去意义 |
| **测试集同源** | 标注集 = 词表（126/126） | 指标必然 1.000，但什么都没测 |
| | 词表自身写错（侄子只收兄之子） | 错误被标注固化，测试跟着错 |
| | 留出集由实现方出（timex 0/12） | 标签 1.000 / 泛化 0.000 |
| **跨类冲突** | `下下个月` 同时在留出集与畸形集 | 规格自相矛盾，无法同时满足 |
| | overlap 门禁与词表合法增长冲突 | 逼出错误决定：故意不收「家母/家严」 |
| **算术与关系** | 槽位百分比合计 110% | 实现方无法猜，只能停下问 |
| | 缓存文本与证据原文的关系未定义 | 索引变成第二份真相，且无对账 |

## 二、十问（写完一节就过一遍）

### 语义

1. **每个时间字段**：这是「内容时间」还是「容器时间」？谁可推导、谁必须一次性盖章？
2. **每个状态转换**：当操作以非法顺序发生时（seal 后 append、未 seal 就 verify、并发 update），行为是什么？
3. **每个派生对象**：它能不能在删掉自己之后从真相完全重建？重建后字节一致吗？

### 测量

4. **每个测试集**：它与实现数据同源吗？同源比例上限写了吗？
5. **每个答案**：除了数量，有没有逐条复核语义？错答案被复制进测试集了吗？
6. **每个留出集**：它独立于规格里枚举的清单吗？（组合 vs 清单，决定测的是能力还是记性）

### 一致性

7. **每个门禁**：它会把正确做法逼成错误做法吗？（overlap 那次就是）
8. **每个新增用例**：它和既有用例有没有跨类冲突？冲突扫描的**键**是什么（expr 单独？还是 expr+anchor+期望码）？

### 算术

9. **每组百分比/配额**：手算过极值吗？——全填满时总和是多少？全为空时是多少？两者都必须合法。
10. **每个比值指标**：分母会不会退化？基线若小于 1，这个比值还有意义吗？

## 三、两条元规则

**元规则 1：改规格必须跑跨类冲突扫描。**
已发生两次（下下个月、家母/家严）。改一处数值或新增一条用例，都可能与别处打架。

**元规则 2：门禁必须配一条「正确做法能过」的证明。**
每写一条 FAIL 条件，就要写出一个**合法实现**如何满足它。写不出来，说明门禁设计错了。

## 四、这份清单本身怎么验证

看下一轮 M4 有没有再出现第十二处。
如果能连续两个里程碑不再需要本清单，说明规格写作已经内化了这些检查。
