## 2. 三处反差，每一处都是一个结论

### 2.1 R1 / R3：模型满分，真人不及格

```
qwen 1.00 / 1.00    glm 0.40 / 0.40    真人 0.07 / 0.07
```

真人聊天几乎不以问句开场，也几乎不会只问一个问题。
**这两条规则不是从人身上学来的，是刻意规定的 AI 说话方式。**

→ 结论：PCS 衡量的是**与人格设定的一致度**，不是拟人度。

### 2.2 R5：真人几乎总是做到，模型做不到

```
真人 0.98 / 0.94    qwen 0.40    glm 0.80
```

「先复述对方说的内容」是人类聊天的自然习惯，模型反而做不到。

→ 结论：这才是真正有「人类基线」的规则；模型在这里确实不如人。

### 2.3 R6：同一个人，换模式就掉分

```
真人·情绪 1.00    真人·咨询 0.88
```

咨询场景里，「需要授权」「可以去申请」是正确回答，词表却判失败。

→ 结论：**规则有效性依赖会话模式**；跨模式比较 PCS 无意义。

## 3. R3 的歧义被这张表量化了

同一批真人回复，两种读法：

| 读法 | 真人通过率 | 区分度 |
|---|---|---|
| ≤1（0 个也通过） | **1.00** | **零**——所有人都过 |
| =1（必须恰好一个） | **0.07** | 明确区分 |

**这不是文字游戏，是「这条规则到底有没有用」的区别。**

在 ≤1 读法下，R3 对任何受测者都恒为 1.00，等于没测。
所以「恰好一问」是唯一有信息量的读法——这为修订提供了独立于标注者的理由。

## 4. 论文里的一段

> 我们把同一套人格规则分别用于两个模型与两段真实中文对话（共 80 条真人发言）。
> 模型在「先问一句」「恰好一问」上得分为 1.00 / 0.40，而真人仅为 0.07 / 0.03；
> 反之在「先复述」上真人为 0.98 / 0.94，模型为 0.40 / 0.80。
> 这表明该规则集描述的是**对 AI 的规定**而非人类行为；
> PCS 因此应解释为「与人格设定的一致度」。
> 此外，同一位真人从情绪对话切换到咨询对话时，「不给建议」的通过率由 1.00 降至 0.88，
> 其中被判失败的均为正确回答，说明规则的有效性依赖会话模式。
