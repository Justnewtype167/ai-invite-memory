# 论文提纲（先定数字，后写正文）

> 原则：**每一节先写清「要证明什么、用哪个已测的数字、缺哪个数字」，再动笔。**
> 缺数字的节，要么删，要么降级为「讨论」。

---

## 0. 一句话主张

> 长期陪伴型 AI 的「人格」不该是一份谁也不知道改没改过的状态，
> 而应是**一个可以从证据重算出来的函数输出**；并且必须把**内容身份**（是不是同一份字节）
> 与**行为身份**（表现得像不像同一个人）**分开测量**。

目标读者：记忆系统 / 人机交互 / 可信 AI 三个社区的交集。

---

## 1. 标题与摘要骨架（每句后面标支撑数字）

**候选标题**

```
中文：可重算的人格：把内容身份与行为身份分开测量
英文：Recomputable Persona: Separating Content Identity from Behavioral Identity
      in Long-Lived AI Companions
```

**摘要五句（逐句对应证据）**

| 句 | 内容 | 支撑 |
|---|---|---|
| 1 | 长期记忆系统的成本随对话线性增长，且无法跨设备/跨模型迁移 | 引文（Mem0/Letta/MSA） |
| 2 | 我们提出三层架构：不可变证据 / 可重算内核 / 每模型投影 | 4 个包、206 测试 |
| 3 | 同一份证据在不同进程、不同设备上重算得到同一内核（kid 一致） | 跨进程实测 |
| 4 | 定义行为身份 PCS = 一致率 × min(自洽率)，并在两个真实模型上测量 | PCS 0.75 |
| 5 | 跨模型时内容身份必然改变（kid 不同），而行为身份仍可保持 | kid 不同 / PCS 0.75 |

## 2. 章节大纲

### §1 引言

要证明：问题真实存在，而且现有方案绕不开。

| 用哪个数字 | 出处 |
|---|---|
| 每轮上下文 4k token，20 万条记忆 p50 13ms | bench_recall |
| 胶囊 19,435 字节 / 4 个文件（v1 格式），**不含人格文件** | demo_e2e 第 5 段 |

缺：真实用户规模数据（我们用合成语料，必须声明）。

### §2 相关工作

要证明：**分开测内容身份与行为身份**这件事此前没人做。

| 对比对象 | 差异点 |
|---|---|
| EverMemOS / EverOS | md 即真相、可编辑、无追加链 |
| Mem0 / Letta / Zep | 抽取式记忆，无人格可重算性 |
| Portable Memory (.mem) | 可搬，但无确定性与一致性度量 |
| BRIDGE / MENTOR | 研究人格漂移，但无形式化身份 |
| 长上下文（100M token 级） | 「塞得起也带不走」 |

缺：逐篇的定量对比（只做定性）。**要诚实写明：未做横向实验。**

### §3 架构

要证明：三层 + 单向派生 + 不可腐蚀，是**结构性**而非工程性的选择。

| 用哪个数字 | 出处 |
|---|---|
| 改 1 字节必被发现（哈希链） | M1，E_TAMPER |
| 删索引后仅凭证据可复活 | M1 测试 |
| 手改内核 → 拒绝 + `tamper_healed` 审计行 | M4 |
| 提案只能影响 `self.style` / `self.conduct`，canon 由 directive 独占 | M5 |

缺：没有形式化证明（只有实现层面的不变量）。**写成「实现保证」，不写成「定理」。**

### §4 内容身份：可重算

要证明：`kid` 是内容的函数，不是运行的函数。

| 用哪个数字 | 出处 |
|---|---|
| 同进程 100 次编译，字节一致 | M4 |
| **跨进程（不同 PYTHONHASHSEED）kid 相同** | M4 |
| 删 `kernel/` 重建，kid 不变 | M4 |
| 设备 B 导入胶囊后重算，kid 相同 | demo_e2e 第 6 段 |
| 提案在 → kid 变；提案走 → kid 回到原值 | M5 三行 |

这张表是全篇最硬的部分，**六个独立验证点**。

### §5 行为身份：PCS

要证明：行为身份可以被定义为可计算的量，且**不是相似度**。

| 用哪个数字 | 出处 |
|---|---|
| `PCS = A × min(C)`，双方全违反时 A=1 但 PCS=0 | M6 手算校验 |
| 判定器双向约束（18/18 accept 过、18/18 violation 拒） | M6/M7 |
| 自比 `PCS = C(a)`（校准线） | M6 实测 |

**已完成**（M8）：60 条留出集盲评，一致率 **0.900**，Cohen's κ **0.690**。
必须同时报告三轮递进（0.00 → 0.56 → 0.69），说明改进来自两处：规则写成可执行判定、复述定义成共享子串。

### §6 跨模型实验（数字已用可判定判定器重算）

要证明：换模型 → 内容身份必变，行为身份只部分保持，且漂移可定位。

| 数字 | 值（v2 判定） | 旧宽判定（作废） |
|---|---|---|
| qwen3.5:9b 自洽率 C(a) | **0.867** | 1.00 |
| glm4:9b 自洽率 C(b) | **0.800** | 0.87 |
| 一致率 A | **0.733** | 0.87 |
| **PCS** | **0.587** | 0.75 |
| kid（qwen / glm） | 不同 | 不同 |

**失败规则不同**：qwen 弱于复述（0.40），glm 弱于先问（0.40），
两者在「不给建议」上只有 0.80 / 0.60。

这是图 1，也是全篇唯一一张「两个真实模型」的表。

### §7 多轮稳定性（数字已重算）

要证明：坍塌可以被定义为可测的量，且缺数据不会伪装成稳定。

| 数字 | qwen3.5:9b | glm4:9b |
|---|---|---|
| 坍塌率 R | **0.389**（7/18） | **0.556**（10/18） |
| 归一化坍塌位置 D | **0.657** | **0.635** |
| 旧宽判定下的 R / D | 0.17 / 0.80（作废） | — |

**新旧结论相反**：宽判定下「基本不崩」，可判定规则下「三分一到一半会崩，崩在中后段」。
这个差别完全来自判定器效度。**这一条本身是论文的卖点**：
不先验证判定器，多轮稳定性的结论会完全反过来。

### §8 讨论：能证明什么、不能证明什么

这一节决定论文的可信度。**必须逐条列出不能声称的东西**（见 §4 本提纲）。

### §9 局限与伦理

- 中文优先，非通用多语言
- 合成语料，无真实长期用户
- 判定器为规则匹配，非语义理解；效度 κ=0.690，非 1.0，所有数字带此误差
- 留出集在 temp 700 采集，主实验口径为 temp 0，分布略有差异
- 「不可腐蚀」是设计约束，未做对抗性红队测试
- 继承与哀悼：只提出协议设想，未实现

### §10 复现性

```
10 个 tag，235 个测试，0 第三方依赖，Python 3.11+
两个本地模型（qwen3.5:9b / glm4:9b），全部离线可跑
一条命令复现实验：python tools/pcs_matrix.py --models …
```

## 4. 不能声称的东西（写作纪律）

| 不能写 | 为什么 |
|---|---|
| 「通用记忆系统」 | 只有中文优先实现 |
| 「人格保真 / 人格一致」 | 只证明了**可重算**，没证明「像人」 |
| 「模型换掉后人格不变」 | 实测 kid 必变，PCS 也只是 0.75 |
| 「长期人格漂移可测」 | 只跑了单次，没跑跨月 |
| 「优于 Mem0 / Letta」 | 没做横向实验 |
| 「经过人工评估」 | 没有 |

**这六条如果不写清楚，论文会被一句话打回；写清楚了，它反而成为可信度来源。**

## 5. 投稿策略（我的建议）

```
首选  arXiv 预印本（cs.CL 交叉 cs.HC）
理由  主要贡献是可复现的工件 + 测量方法，不是 SOTA
      会议审稿周期内，工件可能继续演进，预印本能先占位
次选  带 artifact 评审的会议/工作坊（看重可复现性）
```

**不建议**直接投顶会主会：样本太薄（一个跨族组合、无人工评估），会被拒，且拒稿意见会拖慢迭代。

## 6. 如果要让实验更强，只做这三件

| 优先 | 事项 | 成本 | 收益 |
|---|---|---|---|
| 1 | **人工一致性校验**（3 人 × 60 条回复，算与判定器的一致率） | 半天 | 直接消掉最致命的审稿意见 |
| 2 | 更狠的探针（把 C_final 压到 0.5 附近） | 一天 | 让「会崩」有证据 |
| 3 | 第三个模型（同族小尺寸 qwen3:4b） | 半天 | 三条对比线而非一条 |

**其余实验都不值得做。** 比如「更大模型」「更多探针」「跨语言」，边际收益低。
