# 人类基线：把六条规则套到真人回复上（M8.4）

> 用户提供了两段真实中文对话（11 个月 / 数月，共 80 条本人发言）。
> 我把六条人格规则**原样**套到这些真人回复上，看会得到什么分数。
>
> **结果推翻了一个隐含假设：我们一直在拿「规则通过率」当「人格一致性」，但真人几乎通不过其中两条。**

---

## 1. 真人回复的规则通过率

| 规则 | 情绪对话（46 条） | 咨询对话（34 条） |
|---|---|---|
| R1 先问一句 | **0.07** | **0.03** |
| R2 不用形容词 | 1.00 | 1.00 |
| R3 两句以内恰好一问 | **0.07** | **0.03** |
| R4 四十字以内 | 0.96 | 0.97 |
| R5 先复述 | 0.98 | 0.94 |
| R6 不给建议 | 1.00 | **0.88** |

对照组：两个模型在同一批探针上的自洽率是 **0.867 / 0.800**。

**模型比写这些句子的人更符合这套规则。**

## 2. 这说明什么

### 2.1 规则不是人类行为的描述，是对 AI 的规定

```
R1 / R3 要求「先问一句」「恰好一问」→ 真人通过率 3–7%
```

真人聊天极少以问句开场、极少只问一个问题。这两条不是从人身上学来的，
是刻意规定的 AI 说话方式。这没问题——但如果论文说「PCS 衡量像不像人」，那就是假的。

**正确表述：PCS 衡量「像不像这份人格设定」，不是「像不像人」。**

### 2.2 有些规则本来就是人类常态

```
R5 先复述     → 真人 94–98% 自然做到
R2 不用形容词 → 真人 100%（日常聊天本来就不堆形容词）
```

这两条测的是「AI 有没有做到人自然做到的事」——它们才是真正有人类基线的规则。

### 2.3 规则依赖会话模式（新发现）

```
R6「不给建议」：情绪对话 1.00，咨询对话 0.88
```

咨询场景里，「需要授权」「可以去申请」这类回答是正确的专业回答，
但词表里有「需要」「可以」→ 判失败。

**同一套规则，在两种会话模式下含义相反。**

## 3. 两种会话模式（第二段对话揭示的）

| | 情绪模式（第一段） | 咨询模式（第二段） |
|---|---|---|
| 谁在说话 | 两个人互相打气 | 一个人问、一个人答 |
| 轮次 | 2–8 字 | 问：短；答：可达 60+ 字 |
| 答案形态 | 附和、自嘲、把事说小 | 判断、原因、后果 |
| 建议 | 不请自来是冒犯 | 是核心价值 |
| 我们的规则 | 大致适用 | **R6 直接冲突** |

## 4. 对 PCS 的影响（必须写进论文）

```
PCS 只在「情绪支持模式」下有定义
咨询模式需要另一套规则（或对 R6 做模式门控）
跨模式比较 PCS 没有意义
```

**这不是缺陷补丁，这是度量的适用域。**
任何声称「人格一致性可测量」的工作，都必须先说清在哪种模式下测。

## 5. 论文里可以写的一段

> 我们把同一套人格规则套到两段真实中文对话的 80 条真人回复上。
> 结果：真人几乎不满足「先问一句」（7%）与「恰好一问」（7%），
> 但高度满足「先复述」（94–98%）与「不用形容词」（100%）。
> 这说明该规则集是对 AI 的规定，不是对人类行为的描述；
> 因此 PCS 应被解释为「与人格设定的一致度」，而非「拟人度」。
> 此外，「不给建议」在咨询模式下通过率从 1.00 降到 0.88，
> 其中被判失败的恰是正确回答——规则的有效性依赖会话模式。
