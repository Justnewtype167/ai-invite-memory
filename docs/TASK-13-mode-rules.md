## 0. 先看数据：两种模式到底差在哪

同一批真人发言（情绪 97 条 / 咨询 94 条，两个说话人）：

| 指标 | 情绪 | 咨询 |
|---|---|---|
| 长度中位 | 13 字 | 9 字 |
| 长度 90 分位 | 27 字 | 21 字 |
| 出现问号 | 8/97 = 8% | 12/94 = 13% |
| 含判断词或数字 | 53% | 62% |
| **含建议词** | **0/97 = 0%** | **15/94 = 16%** |
| 句末标点（中位句数） | 0 | 0 |

**三件可以直接下结论的事**：

1. **建议词是模式的分水岭**：情绪模式 0%，咨询模式 16%——R6 在咨询模式下会误杀 16% 的正确回答
2. **真人几乎不打句末标点**（中位句数 0），所以「句数」这个维度在短消息里失效
3. **真人极短**（90 分位 21–27 字），40 字上限对真人几乎不构成约束

## 2. 咨询模式规则集（五条，全部可判定）

### Q1 `answer_directly` · 直接作答（**v2：改为「不回避」，去掉关键词表**）

```
短句：直接给答案
判定：① 第一个句末标点不是「？」；且
      ② 回复不含回避短语（封闭表）
回避短语：无法 不知 不清楚 不确定 看情况 因人而异 难说 说不好 不好说
```

**为什么换掉旧定义**（实测证据见 §10）：关键词表同时产生两类错误，
而新定义在真人和模型上都更合理。

### Q2 `no_evasion` · 不回避

```
短句：不糊弄
判定：去掉标点空白后，不得等于或仅由下列短语构成（≤8 字且命中）：
      看情况 看你自己 因人而异 不好说 难说 说不好
校准：真人 100% 通过 → 它是下限护栏，不是区分性指标
计分：**计入 C / A / PCS**（与情绪模式的 R2、R4 处理一致）
```

**为什么计入**：情绪模式的 R2（不用形容词）在真人上同样是 100%，也被计入了 C。
若把 Q2 排除，两种模式的 C 就用了不同口径，跨模式对照失去意义。
**代价**：C 里混入了近乎免费的规则，见 §8 的说明。

### Q3 `bounded_length` · 六十字以内

```
短句：六十字以内
判定：去空白后 ≤60 字符（咨询回答允许比情绪模式长）
```

### Q4 `no_adjectives` · 不堆形容词（跨模式通用）

```
与情绪模式 R2 相同：8 词封闭表
```

### Q5 `advice_allowed` · 允许建议（**取消限制型规则，non-scored**）

```
短句：该给建议时给建议
判定：始终 pass —— 它的作用是显式声明「咨询模式下不再检查建议词」
意义：把「模式差异」写进规则文件，而不是藏在代码分支里
计分：non-scored（它不约束行为，无法被违反）
```

**它真正的检验不是「某条回复能过」，而是跨模式对照**：

```
同一条带「建议 / 应该」的回复：
  在 consult 模式下 → pass
  在 support 模式下 → R6 fail
```

这个对照证明「取消限制」确实生效，比单条断言强得多。
见 §5 的 Y7。

## 3. 模式门控（不承诺自动识别）

```
探针带 mode 字段：mode = "support" | "consult"
评分时按探针的 mode 选择规则集；跨模式不计算 PCS
```

**明确不做的**：不实现「从对话内容自动推断模式」。
理由：自动识别会引入一个未验证的分类器，使 PCS 的效度重新变成两个未知量的乘积。
识别器留作讨论，评测只做**条件评测**：给定模式，用对应规则。

## 4. 咨询探针（20 条）

```
数量   20 条 = Q1–Q4 各 5 条
形式   单轮提问，每题绑定 mode="consult"
题目   取材于真实咨询的类型：价格、条件、可行性、平台规则、材料清单
禁区   不含真实公司名、平台名、人名；不引用任何原文
```

**Q5 不设探针**：它是 non-scored 的取消限制型规则，没有「可被违反」的行为，
因此不适合放进 accept/violation 的自检框架。它的检验放在 Y7。

每条探针需带 `accept`（2–3 条）与 `violation`（1 条），
**accept 必须通过对应规则，violation 必须不通过**——与 M8 的判定器自检同一套标准。

## 9. 词内子串陷阱（第 15 处规格缺陷）

旧 Q1 用的是「含判断词表之一」，实际判定结果里出现两类错误：

| 回复 | 旧判定 | 应为 | 原因 |
|---|---|---|---|
| 无需条件，随时可用。 | fail | pass | 「无需」不在词表里 |
| 带身份证、户口本、结婚证及申请表。 | fail | pass | 纯列举，不含任何判断词 |
| 尺寸未定，**能**否上车。 | **pass** | fail | 「能否」内含「能」 |
| 未提供具体内容，**是**否可发。 | **pass** | fail | 「是否」内含「是」 |

**这是词表匹配的通病：命中词内子串。** 同类问题在 M6 的 R5 上出现过一次（「你觉得自己…」被当成复述）。

```
教训：词表匹配必须做「整词或边界」判断，或干脆换成「不含某类短语」这种反向定义
新 Q1 采用反向定义（不回避），两类错误同时消失
真人校准：0.49 → 0.86
```

## 10. 一个必须同时披露的缺陷：C 有地板

```
情绪模式 6 条规则中，R2（不堆形容词）在真人上 100%、在模型上 100%
咨询模式 5 条规则中，Q2（不回避）在真人上 100%
```

这些规则几乎人人都过，所以 **C 的下限被抬高**：
一个把其余规则全做错的模型，仍可拿到约 `2/6 ≈ 0.33`（情绪）/ `约 1/4 ≈ 0.25`（咨询）。

本轮**不改定义**（改了会与已发布的支持模式数字不可比），但必须：

1. 报告里始终给出**分规则表**，让读者看到区分度集中在哪几条
2. 论文局限性一节写明：C 的可比性受规则难度分布影响，绝对值不宜跨数据集比较
