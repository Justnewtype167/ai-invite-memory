# SPEC-CONSTRAINTS · 长期约束（不要修改本文件）

> 这些是**设计定论**，M1 用不到，但任何实现都不许违背。写代码时遇到冲突，停下来提问，不要自己决定。

## 三层分离（全部架构的地基）

```
L0 证据层  不可变、哈希链、可携带        "到底发生过什么"
L1 内核层  从 L0 确定性重算的产物        "他现在是谁"
L2 投影层  每个模型/载体一个适配器       "他今天怎么说话"
```

## 五条硬规则

| # | 规则 | 为什么 |
|---|---|---|
| P01 | **单向派生**：L1 只能从 L0 派生，禁止 L1→L1 | 否则会「合并世代」，逐代损失，不可逆 |
| P02 | 任何摘要带 `generation` 字段，只有 `generation=0` 可被检索 | 同一件事 |
| P03 | **原文永不归档/删除**，只允许降权 | 删除必须是可验证删除，不是隐藏 |
| P04 | **LLM 只提案，规则来提交** | 保证重编译字节一致 |
| P05 | 用户模型只能影响风格层，**永不能改底线** | 不可腐蚀条款 |

## 可验证性质（论文的全部说服力来源）

1. 确定性重编译：同 L0 + 同策略 ⇒ 字节一致
2. 灾备复活：删掉内核与索引，仅用证据重建
3. 跨模型等价：换模型后 PCS 下降不超过阈值
4. 腐蚀抵抗：N 轮对抗后宪法 1–9 条保持率
5. 成本有界：每轮上下文 ≤ 4k token

## 中文优先（M2 才开始）

- schema 默认 relation-first，不是 vector-first
- 称谓图、相对时间、梗的时效（`a(s,c,t)` 与 `TTL`）用**规则**实现，不调模型
- 繁简/异体/方言字先规范化再哈希

## 事实与时序

- **禁止 latest-wins 覆盖**：冲突保留时间线 + 置信度，并留 `conflict` 事件
- 时间一律 UTC 存储、带时区输入
- 引用旧事必须能溯源到 `event.id`；不能溯源的陈述必须标为推断

## 语言与风格

- 代码与提交信息用英文；文档与用户可见文案用中文
- 不写「未来将支持」「业界首个」这类话
