# 真实对话的结构（从一段 11 个月的两人聊天里提取）

> 来源：用户本人提供的一段真实中文对话（2025-11 至 2026-10，两人，数百轮）。
> **本文件只记录结构，不保留任何原文、人名、公司名、金额。**
> 目的：让探针的**用户输入**像真人说话，而不是像作文。

---

## 1. 八条结构特征

| # | 特征 | 观察 |
|---|---|---|
| 1 | **轮次极短** | 大量 2–8 字的回应（一个字、两个字的肯定/否定很常见） |
| 2 | **不写情绪** | 难受靠事实传递（拖薪、投递无回音、裁员），不靠形容词 |
| 3 | **口语疑问式** | 「好找不」「咋样」「做啥的」，不是「如何」「是否」 |
| 4 | **方言与语气词** | 哇、啊、吧、呗；个别方言词 |
| 5 | **表情当标点** | 坏消息后面跟一个笑哭/破涕为笑，是自嘲而不是开心 |
| 6 | **求建议是显式的** | 「那你现在怎么打算」「有机会介绍哇」——不暗示，直接问 |
| 7 | **安慰是间接的** | 不说「我理解你」，说「还能活着就不错了」这种把事说小的方式 |
| 8 | **长期异步** | 隔几周、几个月再联系，靠一次「你现在咋样」维持关系 |

## 2. 这些特征对探针意味着什么

```
旧探针输入   我今天很累。              ← 书面、抒情、不像真人
新探针输入   不好找啊。                ← 短、口语、没头没尾
```

**输入变短变糙之后，R5（先复述）会变难**——因为可复述的字更少。
这正是我们想测的：真实输入下，人格规则还守得住吗。

## 3. 隐私处理（必须遵守）

```
① 原文不入库、不进测试夹具、不进论文
② 探针只借「说法方式」，不借「具体内容」：
   无真实人名、无公司名、无金额、无地点
③ 地名/行业等可识别信息一律抽象化（做外贸 → 做这行）
```

## 4. 与现有探针的关系

```
probes.jsonl       30 条，书面化场景（基线）
probes_more.jsonl  30 条，半书面（M8.3 扩量）

```
