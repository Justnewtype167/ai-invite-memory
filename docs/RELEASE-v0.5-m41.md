## 明确没有的东西（M5 之后再说）

1. **没有 LLM**：人格局限于规则可得的部分（canon 来自 directive、承诺来自关键词）
2. **没有向量检索**：只有词法检索，同义改写召回不了
3. **没有 `proposal` 事件**：模型还进不了链路
4. **中文覆盖是高频繁集**：称谓 152 条、时间四组原语、梗 28 条

## 为什么现在要归档

M5 会把「不确定性」放进链路。一旦 `kid` 开始漂移，你需要能回答一个具体问题：

> 是模型的提案让它变了，还是我们的代码把确定性弄坏了？

有这份归档，答案是：**拿同一份证据，用 v0.5-m41 和新版本各算一次，比 kid。**

没有它，你只能猜。
