# 方差与分辨率：PCS 到底能分辨什么（M8.2）

> 这一节补两件事：**置信区间**（原来只有点估计）和 **同模型自比基线**（原来没有）。
> 结论比预期重要：**在采样解码下，PCS 分辨不出「换模型」与「同一个模型换一次」的差别。**

---

## 1. 按探针 bootstrap（temp 0，n=30，4000 次）

| 指标 | 点估计 | 95% CI |
|---|---|---|
| `C(qwen)` | 0.867 | [0.733, 0.967] |
| `C(glm)` | 0.800 | [0.633, 0.933] |
| `A` | 0.733 | [0.567, 0.867] |
| **`PCS`** | **0.587** | **[0.380, 0.780]** |
| **判定器 κ**（60 条留出集） | **0.690** | **[0.420, 0.896]** |

**PCS 的 CI 宽达 ±0.2**，因为它只有 30 条探针。这是必须写进论文的事实。

## 2. 按 seed 的方差（temp 700，各 4 个 seed）

| 模型 | C 均值 | 标准差 | 范围 |
|---|---|---|---|
| qwen3.5:9b | 0.783 | 0.033 | [0.767, 0.833] |
| glm4:9b | 0.850 | 0.043 | [0.800, 0.900] |

**注意**：temp 700 下 glm 反而更高（0.850 vs 0.783），与 temp 0 下的排序（0.867 vs 0.800）相反。
而两个模型的差值（0.067）**与各自的 seed 标准差（0.033 / 0.043）同一量级**——
**在这个样本量上，模型之间的排序不可靠。**

## 3. 关键发现：同模型自比基线

| 比较 | temp 0 | temp 700 |
|---|---|---|
| qwen 与自身 | **1.000**（确定性，必然） | **0.622** [0.562, 0.664] |
| glm 与自身 | 1.000 | **0.758** [0.720, 0.780] |
| **qwen vs glm** | **0.587** | **0.576** [0.511, 0.639] |

### 怎么读这张表

```
temp 0   ：换模型（0.587）明显低于同一个模型（1.000）→ 能分辨
temp 700 ：换模型（0.576）与同一个模型换一次（0.622 / 0.758）几乎重合 → 分辨不出
```

**在采样解码下，「换了个模型」和「同一个模型重跑一次」在 PCS 上看起来一样。**

## 4. 这为什么重要

它给 PCS 的使用条件划了线：

```
PCS 只在固定解码（temp 0）下才有分辨力
若要用于采样解码场景，必须对每个模型平均 N 次采样，否则测的是噪声
```

**这也解释了为什么单次采样下的「人格一致性」讨论没有意义**——
连模型自己都做不到跟自己对得上。

## 5. 论文里可以写的一段

> 在贪心解码下，同一模型的自比为 1.000，跨模型为 0.587（95% CI [0.380, 0.780]），
> 二者可分。但在温度 0.7 的采样解码下，同一模型不同 seed 的自比降至 0.622（qwen）与 0.758（glm），
> 与跨模型的 0.576（95% CI [0.511, 0.639]）基本重叠。
> 也就是说，**单次采样下「换了一个人」与「换了一次采样」在行为身份度量上不可区分**；
> 要度量跨模型差异，必须先固定解码或对多次采样取平均。

## 6. 对后续实验的要求（写进规格）

1. 所有 PCS 报告必须带 95% CI
2. 主表用 temp 0（确定性、可复现）
3. 若要报采样场景，必须报 N≥5 次采样的均值与标准差
4. 模型间排序只有在差值 > 2×seed 标准差时才可下结论
