# 判定器效度检验（人工 60 条）：**不成立**

> 2026-10-30，规格方本人对 60 条回复做盲判（不看机器判定）。
> 结论：**判定器与人的一致性只有 0.60，Cohen's κ ≈ 0.00 —— 与随机不可区分。**
>
> 因此 M6 / M7 里的 `C`、`PCS`、`R`、`D` **不能被当作「符合人格规则」的测量值**。

---

## 1. 原始结果

```
可比样本      58 条（排除「不确定」2 条）
一致          35 条
一致率        0.6034
Cohen's κ     -0.0030      ← 与随机猜测无法区分

混淆矩阵（机器, 人）
  机器 pass / 人 pass    31
  机器 pass / 人 fail    14    ← 假阳性
  机器 fail / 人 pass     9    ← 假阴性
  机器 fail / 人 fail     4
```

## 2. 关键诊断：不是「判定器普遍不准」，是「语义规则判断不了」

按规则拆开，两类规则的差距极其明显：

| 规则 | 一致 | 类型 |
|---|---|---|
| 一次回答不超过两句，最多只问一个问题 | **11/13 = 0.85** | 机械 |
| 每次回复控制在 40 个字以内 | **9/10 = 0.90** | 机械 |
| 不使用温柔、体贴、善解人意这类形容词 | 3/6 = 0.50 | 语义 |
| 回答前先问一句对方现在最在意什么，再给建议 | 6/11 = 0.55 | 语义 |
| 不追问原因，不评价对错，不说应该 | 4/11 = 0.36 | 语义 |
| 收到负面经历时先复述对方说的内容，再回应 | **2/7 = 0.29** | 语义 |

```
机械规则合计     20/23 = 0.87
语义规则合计     15/35 = 0.43
```

**这就是全部原因：人格规则大多是语义的，而判定器是关键词匹配。**

## 3. 三条必须记下的分歧实例

| 回复 | 规则 | 机器 | 人 | 为什么 |
|---|---|---|---|---|
| 你感到失望了。 | 先复述对方说的内容，再回应 | fail | pass | **这正是在复述**；关键词表里没有「你感到…」 |
| 今天累了吗？ | 不追问原因，不评价对错 | pass | fail | 该问句本身就在探问状态，人判为追问 |
| 你感到自己没用吗？ | 先问一句「最在意什么」，再建议 | pass | fail | 问的是感受，不是「最在意什么」 |

人读的是**意图**，机器读的是**字面**。

## 4. 这推翻了什么、没推翻什么

### 推翻

| 数字 | 原来的说法 | 现在只能说 |
|---|---|---|
| `C(qwen) = 1.00` | 完全遵守六条规则 | 关键词层面全过，**语义层面未知** |
| `PCS = 0.75` | 行为身份相似度 0.75 | **未经效度检验的自动指标** |
| `R = 0.17` / `D = 0.80` | 多轮稳定性 | 同上 |

### 没推翻

```
证据链、哈希、胶囊、跨进程 kid 一致、提案进出、降级容错
—— 这些与判定器无关，全部仍然成立
```

**架构是好的；坏掉的是「我们用什么方法判断一句话符不符合规则」这一环。**

## 5. 修法（按代价排序）

| # | 方案 | 代价 | 能解决 |
|---|---|---|---|
| 1 | **规则分级**：机械约束用确定性判定（已验证 0.87），语义约束一律不用关键词判定 | 小 | 立刻止血 |
| 2 | 语义规则改用 LLM 判定（2-of-3），再用人工 60 条做效度检验 | 中 | 能到 0.8+ 吗，需实测 |
| 3 | 把「人格规则」改写成可机械判定的形式（写规则时就约束表达） | 大，但方向最正 | 根治 |

**我的建议：1 + 3 同时做，2 作为过渡。**

- 1 让当前数字立刻有正确的标注
- 3 是最有价值的：**「可判定的规则才是规则」**，这一条本身就是论文的一个论点
- 2 能在短期内把语义规则的判定拉起来，但引入不确定性，需单独报告两个数字

## 6. 这句话要写进论文

> 我们用一个 60 条的盲评发现，关键词级判定器与人工判定的一致性为 0.60（κ≈0），
> 且失败高度集中在语义规则（0.43）而非机械规则（0.87）。
> 这表明：**人格一致性度量若不在机械可判定的规则上定义，就必须引入语义判定器并报告其效度。**

**这是负面结果，但它让整篇工作从「我们测了几个数」变成「我们知道自己测的是什么」。**

# 终局：留出集结果（正式数字）

> 留出集 60 条，与调参集零交集，规则/判定/呈现全部冻结后标注一次。
> **一致率 0.900，Cohen's κ = 0.690 —— 两项达标（≥0.80 / ≥0.65）。**

## 1. 三轮递进

| 轮次 | 规则形态 | 判定器 | 一致率 | κ | 结论 |
|---|---|---|---|---|---|
| v1 | 散文（模型提议） | 关键词匹配 | 0.603 | **-0.003** | 与随机无异 |
| v2 | 可判定（同批调参） | 六个算子 | 0.783 | 0.560 | 有效改进，未达标 |
| **v3** | **可判定 + R5 修正** | **六算子 + 留出集** | **0.900** | **0.690** | **达标** |

**v1 → v3 的 κ 从 0.00 升到 0.69，改动只有两处：把规则写成可执行判定、把复述定义成共享子串。**

## 2. 分规则（留出集 60 条，每规则 10 条）

| 规则 | 一致 | 说明 |
|---|---|---|
| R1 先问一句 | **10/10 = 1.00** | 结构判定完全可靠 |
| R2 不用形容词 | **10/10 = 1.00** | 封闭词表 |
| R4 四十字 | **10/10 = 1.00** | 计数 |
| R5 先复述 | **9/10 = 0.90** | 从 0.47 升到 0.90（改定义起效） |
| R6 不给建议 | 9/10 = 0.90 | 封闭词表 |
| **R3 两句一问** | **6/10 = 0.60** | 唯一弱项，见 §3 |

## 3. 唯一弱项 R3 的真相：不是判定器错，是标注滑手

R3 的 4 条分歧全部是这种情形：

```
回复：你今天很累。          → 1 句 0 问，按定义必然 pass
回复：他答应你的事，没有做到。 → 1 句 0 问，必然 pass
回复：明天考试，确实需要早点休息。→ 1 句 0 问，必然 pass
回复：你不想和家里人说这件事。 → 1 句 0 问，必然 pass
```

**四条都被标成「否」，但按定义不可能不通过。**

进一步的证据：留出集是「同一句回复 × 六条规则」的结构，
`明天考试，确实需要早点休息。` 这一句里，
R3 被标「否」（应为是）、R6 被标「是」（含「需要」，应为否）——**两条标签恰好互换**。

## 4. 这条要写进论文（它本身是个发现）

> 计数型规则（R3）在人工标注中最不稳定：四条分歧全部是「一句话被判成不符合两句以内」，
> 且出现两条标签互换的情况。
> 结构性规则对机器友好，但对人的注意力要求高——**标注指南必须给出逐条示例**。

## 5. 正式结论

```
一致率 0.900   κ 0.690   n=60   留出集，未参与任何调参
可判定化的六条规则里，五条达到 0.90 以上一致
唯一弱项 R3 的偏差来自标注而非判定
```

**方法论成立**：把人格规则写成可执行判定，再用留出集盲评验证，可以得到 κ≈0.69 的可靠测量。
这足以支撑「行为身份可测」这一主张，但**不足以宣称「判定器与人完全一致」**。
