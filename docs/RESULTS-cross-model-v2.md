# 跨模型结果 v2（用 M8 的可判定判定器重算）

> **这份取代 `RESULTS-cross-model.md` 里的旧数字。**
> 旧数字用宽判定（关键词匹配）算，已被 60 条留出集证明效度不足（κ 0.00）；
> 新数字用 `rules_v2.json` 的六条可执行规则，判定器效度 κ=0.690（留出集）。
>
> 重算不需要模型调用：回复文件都在，只换判定器。

---

## 1. 主表

| 指标 | 旧（宽判定） | **新（可判定）** |
|---|---|---|
| `C(qwen3.5:9b)` | 1.00 | **0.867** |
| `C(glm4:9b)` | 0.87 | **0.800** |
| `A` | 0.87 | **0.733** |
| **`PCS`** | 0.75 | **0.587** |

```
PCS = A × min(C_a, C_b) = 0.733 × 0.800 = 0.587
```

## 2. 漂移的定位更清楚了

| 规则 | qwen | glm | A |
|---|---|---|---|
| R1 先问一句 | 1.00 | **0.40** | 0.40 |
| R2 不用形容词 | 1.00 | 1.00 | 1.00 |
| R3 两句一问 | 1.00 | 1.00 | 1.00 |
| R4 四十字 | 1.00 | 1.00 | 1.00 |
| R5 先复述 | **0.40** | 0.80 | 0.60 |
| R6 不给建议 | 0.80 | 0.60 | 0.40 |

**换模型丢的是不同的规则，不是同一条规则的同一程度。**

```
qwen 强在「先问后说」，弱在「复述」
glm  强在「复述」，弱在「先问后说」
两者在「不给建议」上都只做到 0.6–0.8
```

## 3. 多轮坍塌：新判定下模型确实会崩

| 模型 | R（坍塌率） | D（归一化首崩位置） | 违反探针 |
|---|---|---|---|
| qwen3.5:9b | **0.389** | 0.657 | 7/18 |
| glm4:9b | **0.556** | 0.635 | 10/18 |

旧判定下 qwen 的 `R` 是 0.17、`D` 是 0.80——**看起来「基本不崩」。**
换成可判定规则后，**qwen 有 39%、glm 有 56% 的多轮探针至少违反过一次**，
而且首次违反平均发生在**全程的 64–66% 处**（不是最后一轮才崩）。

```
旧结论：多轮里基本不崩
新结论：多轮里三分一到一半会崩，崩在中后段
```

**这个差别完全来自判定器效度，不是模型行为变了。**

## 4. 为什么旧数字偏高

```
R5「先复述」：旧口径把「你觉得自己…」也算复述（关键词表被放宽过），
              新口径要求与用户消息共享 >=2 字，模型做不到
R1「先问一句」：旧口径不检查「必须是第一个标点」，新口径检查
多轮：旧口径对中间轮次宽松，新口径逐轮判
```

## 5. 论文里可以写的一句话

> 在六条可执行人格规则上，两个家族、参数量相近的模型自洽率分别为 0.867 与 0.800，
> 行为身份分 PCS = 0.587；但它们失败的规则不同（qwen 弱于复述，glm 弱于先问），
> 说明模型替换造成的是**局部能力差异**，而非整体人格漂移。
> 多轮条件下，两者分别有 38.9% 与 55.6% 的探针至少违反一次规则，
> 首次违反平均发生在全程约 65% 处。

## 6. 局限

1. 判定器效度 κ=0.690（不是 1.0），所有数字都带这个误差
2. 每个模型只有 30 条单轮 + 18 条多轮探针，置信区间宽
3. 两个模型都是本地量化版（Q4_K_M），非满精度
4. 判定器在 `temp 700` 的留出集上验证，主实验口径是 `temp 0`
