# 端到端演示

```bash
python tools/demo_e2e.py        # 重跑，输出覆盖 docs/demo/E2E.txt
```

九个段落：写入 60 条对话 → 封存与篡改检测 → 编译人格 → 512 token 预算装配 →
导出胶囊换设备 → 设备 B 重算人格 → 偷改内核被拒 → 中文规则层 → 已知缺口。

**最该看的一段是第 5 段**：胶囊里只有 4 个文件，没有人格。人格是到岸之后算出来的。

> 注：这是 v1 格式（纯文本事件）的情形。M10 起容器支持 `blobs/` 载荷，
> v2 胶囊的文件数会随载荷增加——「4 个文件」只适用于 v1。
