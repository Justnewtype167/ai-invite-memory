## 3. 重算结果：数字降了，而且降得对

| 指标 | 旧（宽判定） | 新（可判定） |
|---|---|---|
| `C(qwen3.5:9b)` | 1.00 | **0.83** |
| `C(glm4:9b)` | 0.87 | **0.73** |
| `A` | 0.87 | **0.77** |
| **`PCS`** | **0.75** | **0.56** |

分规则：

```
R1 先问一句        1.00 / 0.40   A=0.40    ← glm 基本不问
R2 不用形容词      1.00 / 1.00   A=1.00
R3 两句一问        1.00 / 1.00   A=1.00
R4 四十字          1.00 / 1.00   A=1.00
R5 先复述          0.20 / 0.40   A=0.80    ← 两个模型都基本不复述
R6 不给建议        0.80 / 0.60   A=0.40
```

**两个发现**：

1. `R5` 从旧口径的 1.00 掉到 0.20——旧口径把「你觉得自己…」也算复述，**那是错的**
2. 差异的主要来源从「一条规则」变成了「三条」（R1/R5/R6），说明新口径真的在分辨东西

## 4. 我修的一处规格缺陷（否则 κ 会再次假跌）

盲评表 v2 第一版里，`R2`/`R6` 的判定写的是「不得出现词表里的任何一个词」，**但没列出词表**。
`R5` 也没列出每行的候选子串。

**标注者根本没法套用**——这会重演上一次「判定器与人不一致」，但原因是判据没给全。

已修：

```
R2 → 判定：回复中不得出现：温柔、体贴、善解人意、暖心、温暖、耐心、细腻、贴心
R5 → 判定：回复必须包含「候选子串」中的任意一个 …；候选子串：今天很累、我今天、很累
```

现在每行都自带完整判据，人可以机械套用。
